# 2026-08-09 双脚原始 Hall 持续加载/卸载诊断

这是一组硬件诊断数据，不是 normalization 标定集。数据只包含左右脚分别保存的
15×3 Hall 原始 counts、15 路温度、同主机 monotonic 到达时间、序列号和 valid。
没有生成或推断法向力、切向力、压力、接触力或摩擦系数。

## 连接身份

- left：`98:A3:16:A1:BF:CA`，`hci0`
- right：`98:A3:16:A1:C1:2E`，`hci1`
- 两路由独立进程同时采集；文件内时间为同一主机 monotonic 时钟，但设备帧没有
  硬件时间戳。
- 后续 8 s 复核发现帧头 byte 1 在 left 800 帧、right 799 帧中都恒为 `1`，
  不是设备帧序号。因此当前固件不能提供设备侧丢帧计数；只能使用主机接收帧率、
  到达时间和解析拒绝计数评估链路。

## 人工动作与原始响应

以原始数据中的明显阶跃为准：开头为空载，约 19–20 s 开始双脚持续加载，约
48–49 s 完全卸载，随后记录到约 65 s。加载动作持续约 27 s，期间原始信号没有
清零。

| 项目 | left | right |
| --- | ---: | ---: |
| 帧数 | 6493 | 6490 |
| 有效时长 | 64.996 s | 64.988 s |
| 原始帧率 | 99.883 Hz | 99.849 Hz |
| 拒绝字节/帧 | 0 | 0 |
| int16 端点回绕事件 | 0 | 0 |
| 接近 ±32767 的样本 | 0 | 0 |
| 原始线值范围 | -28283…31659 | -23660…23166 |
| 空载整脚变化中位数 | 853.2 counts | 845.3 counts |
| 持续加载整脚变化中位数 | 65002.1 counts | 10702.8 counts |
| 恢复段最后 5 s 中位数 | 9704.6 counts | 1463.5 counts |

“整脚变化”定义为相对开头空载中位基线的 15 个 `norm([Bx,By,Bz])` 之和，只是
Hall counts 诊断量。相近机械加载下本次 left/right 原始响应约为 6.1:1，不能
解释成力的比例。

持续加载早段/晚段分别为：left 64400.6/65316.2 counts，right
10056.1/10820.1 counts；没有原始信号随持续踩压逐渐消失。卸载后两脚都存在
真实慢恢复，left 更明显。恢复段最后 5 s 的 left 残余主要在 P00、P01、P03、
P04；这不能由显示滤波伪装为已经回零。

本次加载下，以各点加载中位响应除以空载 P99 波动作为单次诊断比值，right 的
P08 约 2.0、P11 约 1.4，明显弱于 right 其他点；left 最低的 P11 约 4.5。
这一次整体踩压不能单独证明通道损坏，因为局部载荷分布并不均匀；正式采集前
应对 P00–P14 逐点做局部加载/释放重复测试，重点复核 right P08、P11。每个温度
通道在 65 s 内的变化不超过约 0.9 °C，未见温度突跳。

两路原始帧约 100 Hz；10 ms 上限内按同主机到达时间贪心唯一配对得到约
88.6 Hz，足够用于 50 Hz 同步观测。该同步不是设备级硬件时钟同步。
