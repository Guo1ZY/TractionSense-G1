# Unitree G1 足底传感器快拆连接件 V1

## 设计结论

这是一版可制造、可继续参数化修改的工程原型。连接不依赖磁铁或魔术贴承受步态载荷：

1. 传感器侧载板用 6 个弹性卡臂包住现有 PCB 外壳边缘。
2. 传感器载板与 G1 脚套之间用两条沿足长方向的捕获式燕尾轨承受竖向、横向载荷。
3. 燕尾轨前端有实体止挡，后端用 Ø5 mm 短快拆销防止反向滑脱。
4. G1 脚由左右防脱唇、前挡块和一根 Ø5 mm 长后跟销固定。

拆卸传感器时，只需拔出短快拆销，将传感器载板沿脚长方向滑出；脚套可以继续留在机器人脚上。

## 已采用的实测/模型尺寸

- 传感器总包络：约 `215.02 × 80.04 mm`
- PCB 外壳高度：约 `10.50 mm`
- 软鞋垫厚度：`10.00 mm`
- 官方 G1 脚模型包络：约 `208.21 × 75.58 mm`
- 燕尾轨间隙：每侧 `0.30 mm`
- 脚侧横向间隙：每侧 `0.46 mm`
- 传感器卡臂初始间隙：`0.28 mm`
- 连接件增加的脚底高度：约 `7.30 mm`

`tools/build_g1_foot_sensor_connector.py` 的 `P` 字典。

## 建议材料与五金

每只脚建议使用：

- 传感器载板：PA12 SLS/MJF，1 件
- G1 脚套：PA12 SLS/MJF；最终版也可改为 PA-CF 或 6061-T6，1 件
- 短快拆销：不锈钢 Ø5 mm，工作长度约 9–10 mm，1 件
- 后跟防脱销：不锈钢 Ø5 mm，工作长度约 85–90 mm，1 件
- 0.5–0.8 mm TPU/硅胶防滑垫：贴在脚套与 G1 脚底接触面，可选

STEP/STL 中的两根销只用于装配表达和选型参照，不建议把塑料打印销用于机器人行走。

按 PA12 密度约 1.01 g/cm³ 粗估，载板约 59 g，脚套约 73 g，每只脚的两件塑料件合计约 132 g，不含金属销和传感器。

## 打印建议

- 首选 SLS/MJF PA12，可避免卡臂和燕尾槽内部大量支撑。
- FDM 原型建议 PA-CF/PA-GF，喷嘴不小于 0.6 mm，层高 0.20–0.28 mm。
- FDM 至少 6 道外壁，燕尾轨、销孔和卡臂根部使用局部 100% 填充。
- 不建议 PLA；反复冲击、环境温升和蠕变会降低可靠性。
- 先打印 30–40 mm 长的燕尾配合试样，确认机器实际需要的间隙。过紧时把 `dovetail_clearance` 增加到 0.40–0.50 mm。
- 首次卡装传感器前，应确认卡臂不会压到 PCB、排线、接口或软鞋垫敏感区域。

## 装配顺序

1. 将橙色传感器载板从 PCB 外壳上方压入，先扣前后卡臂，再依次压入四个侧卡臂。
2. 拔出长后跟销，从后跟方向把紫色脚套滑到 G1 脚底，使左右防脱唇包住脚底外缘，并让脚尖顶到前挡块。
3. 插入 Ø5 mm 长后跟销，确认销的自锁钢珠或 R 形保险卡已完全就位。
4. 将载板上的两条公燕尾从脚套后端推入，滑到前端实体止挡。
5. 插入 Ø5 mm 短快拆销，检查短销已同时穿过载板和脚套。
6. 装好后重新做足底传感器零点标定。

拆卸顺序相反。正常快速拆卸只需要操作第 4、5 步，脚套可以不拆。

## 上机前验证

官方 G1 整机质量约 35 kg，但步态冲击会高于静态重量。V1 在真实机器人行走前至少完成：

1. 尺寸复核：用卡尺测量真实 G1 脚底最大长宽、外缘厚度以及传感器外壳卡扣位置。官方 URDF/STL 与你的硬件版本可能存在修订差异。
2. 空载手动检查：确认燕尾无卡滞，两个销均有二次保险，卡臂无白化和裂纹。
3. 静载逐级测试：500 N、1000 N、1500 N、2000 N，每级保持 60 秒。
4. 剪切测试：前后方向至少 600 N，左右方向至少 300 N，不得出现持续滑移。
5. 循环测试：0–1000 N 至少 10,000 次，检查卡臂根部、燕尾槽顶面和销孔椭圆化。
6. 先在吊架/保护绳条件下低速原地踏步，再逐步进入直线行走。

这版已经通过 CAD 拓扑和导出检查，但尚未替代真实样件的材料试验、疲劳试验或整机安全认证。

- 启动命令：`~/.local/bin/freecad`

- FreeCAD Bridge 工作台：`~/.local/share/FreeCAD/v1-1/Mod/RobustMCPBridge`
- Codex MCP 配置：`~/.codex/config.toml` 中的 `[mcp_servers.freecad]`

FreeCAD 启动后，Bridge 会在本机 `127.0.0.1:9875` 自动启动。新开一个 Codex 会话后即可加载 `freecad` MCP。
