# G1 高/低摩擦切换训练与实机验证

## 目标

在整段测试中保持同一个前向速度指令。首轮建议使用
`vx_cmd = 0.6 m/s`，通过后再逐步提高。策略只能使用可部署的本体状态和
脚底磁阵列观测，不能读取仿真摩擦系数。期望行为是：

- 低摩擦：在检测到接触/滑移变化后缩短步长、降低步频和实际速度，抑制继续滑移；
- 高摩擦：恢复较长步幅、较高步频和接近指令的实际速度；
- 高→低、低→高均在 0.5–1.0 s 内完成主要速度响应；
- 全程不依赖重新启动或 episode reset。

新增任务：

```text
Unitree-G1-29dof-Velocity-Foot-TractionTeacher-MotionFeedback-Switch
Unitree-G1-29dof-Velocity-Foot-TractionMagneticMotionStudent-Switch
```

训练时每个环境在 reset 随机从高/低摩擦开始，随后每 4 s 翻转一次摩擦。约一半环境同时经历高→低，另一半经历低→高。命令在 reset 后固定，因此网络不能用命令变化冒充摩擦适应。

训练随机化的低摩擦范围是 `0.08–0.20`，高摩擦范围是 `0.80–1.20`。
默认验收使用 `μ=1.20 → 0.15 → 1.20` 和 `0.6 m/s`。这两个区间应在
实机材料确定后根据辨识结果校准，不能把仿真 `μ` 数字直接当成材料参数。

## 一键训练

从项目上一级目录运行：

```bash
cd <workspace>
./scripts/train_two_surface_adaptation.sh
```

完整流程依次完成：

1. 从现有 `model_8900.pt` 续训可读取真实摩擦状态的 Oracle Teacher；
2. 导出 Teacher；
3. 在高→低→高→低的连续 Teacher 轨迹上采集 DAgger 标签，并提高切换后
   1 s 样本的权重；
4. 生成保守蒸馏 Student，同时导出“磁阵列估计摩擦 → 冻结 Teacher”的
   无特权候选策略；
5. 分别用正常脚底观测和脚底观测消融进行高→低→高评估。自动门限不通过
   时只保留为候选，不应直接安装到真机。

只验证代码链路时使用：

```bash
./scripts/train_two_surface_adaptation.sh --smoke
```

`--smoke` 只有 2 次 PPO iteration、1 个蒸馏 epoch，不能作为最终模型。

单独续训 Teacher：

```bash
./scripts/finetune_friction_switch_teacher.sh
```

单独评估一个 Student：

```bash
SHARED_POLICY=/absolute/path/to/shared_magnetic_policy.pt \
  ./scripts/evaluate_two_surface_switch.sh

SHARED_POLICY=/absolute/path/to/shared_magnetic_policy.pt \
  ./scripts/evaluate_two_surface_switch.sh --ablate-foot
```

评估会输出：

- `phases.csv`：每个摩擦阶段的稳态速度、横向速度、接触滑移、步频、步长、响应时间和摔倒数；
- `phases.timeseries.csv`：每 20 ms 的切换时序；
- `phases.summary.md`：自动门限和 `PASS/NEEDS_TRAINING` 结论。

默认验收门限包括：零摔倒，高低摩擦稳态速度差不小于 `0.35 m/s`，低摩擦速度不大于 `0.45 m/s`，高摩擦恢复到指令的 75% 以上，切换响应不超过 `1.0 s`，并检查高摩擦步频和步长是否恢复。门限是实验起点，应根据真实材料能力调整，但不能只看“速度不同”；还必须同时看摔倒、横向漂移和滑移。

## 当前实际结果（2026-07-29）

已经完成 64 环境的 `1.20 → 0.15 → 1.20`、恒定 `0.60 m/s` 评估：

| 指标 | 高摩擦 1 | 低摩擦 | 高摩擦 2 |
|---|---:|---:|---:|
| 实际 `vx` (m/s) | 0.634 | 0.331 | 0.447 |
| 步频 (Hz) | 2.506 | 2.875 | 2.481 |
| 单步长度 (m) | 0.255 | 0.109 | 0.182 |
| 接触滑移代理 | 0.023 | 0.047 | 0.018 |
| 摔倒数 | 0 | 0 | 0 |

因此已经看到“低摩擦主动降速、明显缩短步长、随后减少滑移”，但尚未看到
“低摩擦降低步频”；高摩擦恢复时间为 `1.70 s`，也未达到 `1.0 s`。
足底观测消融后仍然无摔倒且没有明显恶化，说明现阶段不能证明行为变化由
足底磁阵列主导。最终报告为 `NEEDS_TRAINING`，不能宣称完整目标已经实现。

另外，`0.9 m/s`、`μ=0.08` 的极端组合连 Oracle Teacher 都出现摔倒。
实机首轮不要按这一组合测试。

### MuJoCo Sim2Sim 结果

最终 1864 维传感策略还在 MuJoCo 中完成了独立地面和同 episode 连续切换验证。
恒定 `0.60 m/s` 指令下，独立地面结果为：

- `μ=0.15`：`vx=0.188 m/s`；
- `μ=1.20`：`vx=0.586 m/s`；
- 两种地面均无摔倒，速度差 `0.398 m/s`，静态矩阵门限通过。

同一个 episode 内执行 `1.20 → 0.15 → 1.20` 时：

| 阶段 | μ | 稳态 vx (m/s) | 响应时间 (s) | 摔倒 |
|---:|---:|---:|---:|---:|
| 0 | 1.20 | 0.585 | — | 0 |
| 1 | 0.15 | 0.189 | 1.25 | 0 |
| 2 | 1.20 | 0.497 | 1.35 | 0 |

关闭 MuJoCo 磁阵列桥接后，返回高摩擦的速度只有 `0.329 m/s`，恢复时间增加到
`3.25 s`，高低摩擦速度差由 `0.352` 降至 `0.198 m/s`。这次 MuJoCo
消融说明足底磁观测确实提供了适应信息。不过正常版本的最大响应仍为
`1.35 s`，所以连续切换总评仍为 `NEEDS_WORK`，不是最终通过。

MuJoCo 当前足底桥没有足够可靠的逐脚 touchdown 时序，因此这一层只验收速度、
横漂、力/滑移代理和摔倒；步频、步长仍以 Isaac 和真实外部相机/动捕为准。

## 两种真实地面的实验步骤

先做“整块地面 A / 整块地面 B”的分离测试，再做边界穿越。推荐使用面积足够的固定板材，避免板材自身移动。低摩擦面可以是可重复铺设的低摩擦薄板，高摩擦面可以是橡胶/防滑材料；两块板必须同高、牢固固定、接缝平整。

1. 用斜板试验估计静摩擦 `μ_s≈tan(θ_start)`，再用水平匀速拉动和测力计
   估计动摩擦 `μ_k≈F_t/F_n`。每块地面至少重复 10 次，测的是
   “G1 脚底材料—地面材料”这一对接触面，不采用材料手册数值。
2. 在安全吊架下，先用两块完整地面分别采集 `0、0.2、0.3、0.4 m/s`
   轨迹，再采集正反方向越界轨迹。必须记录源时间戳、接收时间戳、原始磁
   阵列、有效位、采样周期、关节状态、IMU、命令、动作、外部 `vx/vy`、
   脚部轨迹、地面标签和急停；字段见 `REAL2SIM_DATA_SCHEMA.md`。
3. 用真实记录辨识的不只是 `μ`，还包括接触刚度/阻尼、恢复系数、电机延迟，
   以及磁阵列的零偏、增益、迟滞、噪声、延迟和丢包。把辨识区间写回
   `TractionTwoSurfaceSwitchEventCfg` 和传感器随机化，保留区间而不是只用
   两个固定数。
4. 按“强 Teacher → 连续切换轨迹 → 摩擦估计/DAgger Student”重新训练。
   真实训练集按地面与方向平衡采样，切换后 1 s 样本提高权重；每块地面
   留出至少 20% trial，只用于验证，禁止按单帧随机拆分造成数据泄漏。
5. 完成完整仿真门限检查。正常脚底传感版本必须明显优于
   `--ablate-foot`；否则无法证明行为变化来自脚底传感，也不应上真机。
6. 实机先在安全吊架下，以 `0.3 m/s` 和两块完整地面分别验证站立、起步和
   连续行走，再提高到 `0.6 m/s`。`0.8/0.9 m/s` 只有前一级零摔倒且消融
   证据成立后再测试。控制指令在每次试验中保持不变。
7. 每种地面、每个速度至少随机顺序重复 10 次。分离测试通过后，将前半段
   高摩擦板、后半段低摩擦板连接；两板同高、固定牢靠、接缝平整。标记接缝，
   用外部相机或动捕测量越界时刻，正反方向都测试。
8. 对齐“第一只脚接触新材料”的时刻，计算之后 0.5 s、1.0 s 内的速度、
   步频、步长和接触期脚底水平滑移；不要只用质心速度下降代替滑移减少。

实机最低通过条件：

- 同一速度指令、同一策略文件，低摩擦阶段的步长和步频显著低于高摩擦阶段；
- 低摩擦切换后滑移先短暂上升、随后在 0.5–1.0 s 内下降，且没有摔倒或持续横漂；
- 返回高摩擦后实际速度、步频和步长恢复；
- 脚底观测消融或断开时效果显著变差，证明适应不是固定的时间表；
- 更换试验起点、改变切换时刻后仍成立。

## 重要边界

当前训练中的“中途切换”会同时改变左右脚所接触的全局地面材料，适合先学到快速时序适应，也适合分别在两块完整真实地面上验证。真实机器人跨过两块板的边界时，会经历“一只脚高摩擦、另一只脚低摩擦”的混合接触，这比同步切换更难。

因此，在宣称具备真实边界穿越鲁棒性前，还应增加每只脚独立摩擦或真正的空间分区地形训练，并把左右脚混合摩擦作为单独 stress test。当前实现是必要的第一阶段，不等同于已经解决所有 sim-to-real 偏差；磁阵列的 Real2Sim 标定质量仍然决定最终效果。
