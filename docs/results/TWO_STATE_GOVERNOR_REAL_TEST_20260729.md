# G1 两地面二状态限速器：首轮真机流程

> 2026-07-30 更新：自动判断已经改成 **480 维纯本体历史**。足底/Hall
> 数据不进入分类器，也不作为有效传感依据。MuJoCo 模型不会被真机启动脚本
> 默认加载；必须先在实际两块地面采集并显式安装真机分类器。

## 已实现

限速器位于手柄命令与现有行走策略之间，不改变 ONNX、策略观测维度或关节控制。
同一手柄前进量可以映射为两个安全档位：

- `LOW`：策略收到的前向速度不超过 `0.15 m/s`；
- `HIGH`：策略收到的前向速度不超过 `0.35 m/s`；
- `UNKNOWN/AUTO`：没有新鲜判断信号时按低速处理；
- 横向速度和偏航速度在首轮测试中强制为零；
- 升速斜率 `0.15 m/s²`，降速斜率 `0.80 m/s²`。

默认配置是关闭状态。只有设置 `G1_TRACTION_GOVERNOR=1` 或使用专用启动脚本
才会启用，当前 `policy_dir` 仍是 `config/policy/velocity/foot`。

## MuJoCo 验证

两次测试使用同一个原始前向命令 `0.8 m/s`，限速器分别置为 LOW/HIGH：

| 地面与档位 | 策略命令上限 | 实际平均 vx | 平均绝对 vy | 摔倒 |
|---|---:|---:|---:|---:|
| μ=0.15，LOW | 0.15 m/s | 0.100 m/s | 0.023 m/s | 0 |
| μ=1.20，HIGH | 0.35 m/s | 0.336 m/s | 0.055 m/s | 0 |

速度差为 `0.236 m/s`，高摩擦实际速度约为低摩擦的 `3.36×`。这只证明
限速与现有策略的闭环兼容；LOW/HIGH 的自动识别尚未由真机本体状态验证。

另对完全不读取足底项的480维 `v0` 策略做了消融。低摩擦档设置为
`0.20 m/s` 时，`μ=0.15` 实际 `vx=0.143 m/s`；高摩擦档为 `0.35 m/s`
时，`μ=1.20` 实际 `vx=0.323 m/s`，两档都无摔倒。`v0` 在 `0.15 m/s`
命令附近存在停止死区，因此无足底传感器模式默认把低速档设为 `0.20 m/s`。

## 真机前检查

1. 使用额定载荷足够的顶部保护架，绳长允许脚掌接触地面但不能使机器人倒地。
2. 一人操作手柄，一人只负责硬件急停；清空机器人前后至少 3 m。
3. 固定低摩擦板，防止板材随机器人一起滑动；两种地面先分开测试，不跨接缝。
4. 关闭宇树内置运动服务，确认没有其他进程占用 lowcmd。
5. 首轮不使用 `AUTO`，不发送横向和转向命令。
6. 按 `A` 进入 FixStand，稳定后按 `X` 进入 Velocity；任何异常按 `B`，
   同时由第二人准备硬件急停。

## 启动

把 `<interface>` 替换为连接 G1 的网卡名：

```bash
cd <repo>/deploy/robots/g1_29dof
export G1_REAL_TEST_ACK=YES
./run_two_surface_governor.sh low --network <interface> --log
```

如果足底传感器和 ROS bridge 都不使用，选择480维本体策略：

```bash
cd <repo>/deploy/robots/g1_29dof
export G1_REAL_TEST_ACK=YES
export G1_GOVERNOR_POLICY=sensorless
./run_two_surface_governor.sh low --network <interface> --log
```

该模式的 LOW/HIGH 默认是 `0.20/0.35 m/s`。它不会永久修改
`config.yaml`，退出后下次正常启动仍使用原来的 `foot` 策略。

启动后即使手柄推满，LOW 也只给策略 `0.15 m/s`。手柄组合键：

- `RB + ↓`：LOW；
- `RB + ↑`：HIGH；
- `RB + ←`：AUTO/重新判断；首轮不要使用；
- `B`：进入 Passive。

第一块低摩擦地面只用 LOW。确认连续三次起步、停止均无摔倒后，将机器人断电
搬到高摩擦地面，仍用同一手柄推杆位置，按 `RB+↑` 切到 HIGH。不要在机器人
运动中搬动地面或第一次就跨地面边界。

## 记录与通过条件

启动脚本会输出 CSV，字段包括原始命令、限速后命令、状态、判断来源和分数。
首轮通过条件：

- LOW/HIGH 各连续三次，每次至少 5 s，零摔倒；
- LOW 的限速后命令稳定为 `0.15 m/s`，HIGH 为 `0.35 m/s`；
- HIGH 的外部实测速率明显高于 LOW；
- 横向漂移、偏航和异常脚步没有持续增大。

外部相机至少标定一段已知距离，用视频时间测量真实 `vx`。仅看策略命令不能
证明实际速度不同。

## 当前480维自动分类器

输入严格为普通 G1 `v0` 策略已有的五帧历史：

`5 × (gyro3 + gravity3 + command3 + q29 + dq29 + last_action29) = 480`。

分类器输出 `p_low`，控制器内部直接连接：

- `p_low >= 0.65` 持续 `0.20 s`：进入 `LOW`；
- `p_low <= 0.35` 持续 `1.00 s`：进入 `HIGH`；
- 中间区域保持原状态；
- 未加载模型或输出无效：保持 `UNKNOWN/LOW`，不会盲目升速。

训练脚本会硬截取 `obs[:, :480]`，因此即使系统里存在不准确的足底/Hall
数据也会被丢弃。详细采集、训练和 AUTO 启动命令见
`SENSORLESS_TWO_SURFACE_AUTO_20260730.md`。
